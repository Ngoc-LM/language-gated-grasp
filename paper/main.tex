\begin{abstract}
Language-driven grasp detection places a grasp on the object part named by a free-form prompt. The proposed method steers the GR-ConvNet grasp CNN with FiLM and a \emph{language gate}: a spatial map of cosine similarities between frozen CLIP patch tokens and the prompt embedding. On Grasp-Anything++, the model reaches 68.6\% seen and 57.8\% unseen success (two-seed mean) on the official test split, against 54.7\% and 40.7\% with FiLM alone. A control gate that receives the same CLIP features but not the prompt scores 11.8 unseen points lower in both seeds, so prompt-dependent gating gives 59\% of the gain in harmonic mean over FiLM. Code: \url{https://github.com/Ngoc-LM/language-gated-grasp}.
\end{abstract}

\section{Introduction}
A parallel-jaw grasp~\cite{jiang2011efficient} is a rotated rectangle $g=(x,y,w,h,\theta)$. Language-driven grasp detection conditions $g$ on a prompt such as ``grasp the knife by its handle'', so the model must also locate the named part. On Grasp-Anything++ (1M images, 10M prompts), the reference method LGD~\cite{vuong2024language} is a diffusion model. This work tests whether a single-pass grasp CNN can instead be steered by language. The contributions are (i) a \emph{language gate} that re-weights GR-ConvNet~\cite{kumra2020antipodal} features by CLIP~\cite{radford2021learning} patch--text similarity (\cref{fig:arch}); (ii) a controlled ablation (text-free gate, two seeds) that separates CLIP visual features from prompt-dependent gating; (iii) an evaluation that excludes test scenes and unseen object names from training, with open code.

\section{Related Work}
Generative grasp CNNs~\cite{morrison2018closing,kumra2020antipodal} regress dense grasp maps. CLIPort~\cite{shridhar2022cliport} and CROG~\cite{tziafas2023language} use CLIP for manipulation and referring grasp synthesis, and LGD~\cite{vuong2024language} denoises grasps under text guidance on data built with foundation models~\cite{vuong2024grasp}. Pixel--text score maps from CLIP-style encoders drive dense prediction~\cite{zhou2022extract}; the language gate uses such a map as a spatial prior inside a grasp CNN.

\section{Method}
\textbf{Grasp maps.} As in~\cite{kumra2020antipodal}, the network predicts four $224{\times}224$ maps: quality $Q$, $\cos2\Theta$, $\sin2\Theta$ (doubled angle, as a grasp is $180^\circ$-symmetric) and opening $W$. Targets fill the central third of each ground-truth rectangle. The grasp is read at $\arg\max Q$ of the smoothed maps, with $\theta=\tfrac12\operatorname{atan2}(\sin2\Theta,\cos2\Theta)$ and $h=w/2$.

\textbf{FiLM.} The encoder maps the image to $F\in\mathbb{R}^{128\times56\times56}$, followed by five residual blocks and a decoder. With $t$ the normalised CLIP text embedding, each residual block $k$ is followed by
\begin{equation}
F \leftarrow \big(1+\Delta\gamma_k(t)\big)\odot F + \beta_k(t),
\end{equation}
where $\Delta\gamma_k,\beta_k\in\mathbb{R}^{128}$ come from a zero-initialised linear layer, so each FiLM layer is the identity at initialisation.

\textbf{Language gate (proposed).} FiLM applies the same channel modulation at every pixel, so it can favour one object among several only indirectly. The language gate therefore compares the $14{\times}14$ post-LayerNorm patch tokens $P$ of a frozen CLIP ViT-B/16 with the prompt and re-weights the encoder output:
\begin{equation}
\begin{gathered}
S_{ij}=\cos(W_p\,p_{ij},\,W_t\,t),\\
A=\mathrm{Up}_{56}\big(\sigma(\tau S)\big),\qquad F'=F\odot(1+A),
\end{gathered}
\end{equation}
with learned $W_p\in\mathbb{R}^{256\times768}$, $W_t\in\mathbb{R}^{256\times512}$ and temperature $\tau$ (initialised to 10). The residual form $1{+}A$ only amplifies prompt-matching regions. The \textbf{C0 control} replaces $W_t t$ with a learned vector $q$: its gate sees the same CLIP features but not the prompt (FiLM still receives $t$). \textbf{Loss:} Smooth-$\ell_1$ summed over the four maps. Variant D adds $0.5\,\mathrm{BCE}(\tau S, M)$, $M$ the pooled ground-truth $Q$ mask.

\section{Experiments}
\textbf{Protocol.} Training uses 35,964 Grasp-Anything++ scenes (183,559 prompt--grasp pairs) and validation 734. Testing follows the official LGD split (seen: the 70\% most frequent LVIS categories), restricted to annotated pairs: 1,376 seen and 601 unseen from 727 of 803 object keys. Test scenes, and training pairs whose object name is an unseen test name, are excluded from training. A top-1 grasp is correct if its IoU exceeds 0.25 and its angle error is below $30^\circ$ for some ground-truth grasp of the prompted part; $H$ is the harmonic mean of seen and unseen success. Decoding ground-truth maps scores 97.5\% on 200 validation pairs, the ceiling of the encoding. All runs use AdamW (lr $10^{-3}$, cosine), batch 32, 6 epochs, no augmentation and one T4 (2.5--2.7\,h); checkpoints are selected on 1,000 validation pairs.

\textbf{Results.} Each row of \cref{tab:main} adds one component; A ignores the prompt, so its seen and unseen scores coincide (27.3 vs.\ 27.8). FiLM (B) raises $H$ by 19.1 points, CLIP features behind the text-free gate (C0) add 6.6, and letting the gate read the prompt (C) adds 9.5. Within each seed, C exceeds C0 by 11.8 unseen points and by 6.3 and 4.4 seen points. These gaps exceed both the seed half-ranges (at most 1.9) and the 95\% interval of a two-proportion difference ($\pm5.6$ unseen, $\pm3.5$ seen). Prompt-dependent gating thus accounts for 69\% of the B$\to$C gain on unseen objects, 59\% in $H$ and 38\% on seen objects, where CLIP features contribute most (\cref{fig:qual}). Gate supervision (D, one seed) stays within 2.3 points of C on every split, inside these intervals, so the simpler C is retained.

\textbf{Cost and limitations.} C adds 0.33M trained parameters to B and a frozen 149M-parameter CLIP (12.5\,ms per frame with a cached prompt). Training uses 3.6\% of the images; the intervals ignore that prompts share scenes. The prompt-blind A already exceeds the 18 unseen that LGD~\cite{vuong2024language} reports for GR-ConvNet with CLIP, so the protocols differ and LGD's 48/42 (seen/unseen) are not compared.

\section{Conclusion}
A frozen-CLIP patch--text gate raises the $H$ of a FiLM-conditioned GR-ConvNet from 46.7 to 62.8; the text-free control attributes 9.5 points to prompt-dependent gating.
