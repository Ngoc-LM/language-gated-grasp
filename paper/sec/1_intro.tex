\section{Introduction}
A parallel-jaw grasp~\cite{jiang2011efficient} is a rotated rectangle $g=(x,y,w,h,\theta)$. Language-driven grasp detection conditions $g$ on a prompt such as ``grasp the knife by its handle'', so the model must also locate the named part. On Grasp-Anything++ (1M images, 10M prompts), the reference method LGD~\cite{vuong2024language} is a diffusion model. This work tests whether a single-pass grasp CNN can instead be steered by language. The contributions are (i) a \emph{language gate} that re-weights GR-ConvNet~\cite{kumra2020antipodal} features by CLIP~\cite{radford2021learning} patch--text similarity (\cref{fig:arch}); and (ii) a controlled ablation (text-free gate, two seeds, paired tests) that separates CLIP visual features from prompt-dependent gating, with open code.
